# Лабораторна робота №2

Графічний редактор об’єктів на C++ Win32 API.

Номер у журналі: 17. Масив фігур: статичний `Shape* pcshape[117]`.

Варіант: червоний суцільний гумовий слід; прямокутник від центру до кута,
чорний контур і сіре заповнення; еліпс за двома кутами,
чорний контур без заповнення; поточна фігура показана в заголовку вікна.

Файли:

- `Lab2.cpp` — головне вікно, меню та обробка подій.
- `Shape.h` — абстрактний базовий клас і похідні класи.
- `Shapes.cpp` — реалізація відображення фігур.

Компіляція в PowerShell:

```powershell
C:\msys64\ucrt64\bin\g++.exe -std=c++17 -Wall -Wextra -municode -mwindows -static -static-libgcc -static-libstdc++ Lab2.cpp Shapes.cpp -o Lab2.exe
```

Запуск:

```powershell
.\Lab2.exe
```
