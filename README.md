# Лабораторна робота №1

Номер у журналі — 16. В1 = 0, В2 = 1.

Файли: Lab2.py — головне вікно та меню; module1.py — введення тексту;
module2.py — вибір числа від 1 до 100 горизонтальною смугою прокручування.

Запуск:
```powershell
python Lab2.py
```

Підготовка EXE (перед цим закрий запущений Lab1.exe):
```powershell
python -m PyInstaller --onefile --windowed --name Lab1 Lab2.py
```

Результат: dist/Lab1.exe.
