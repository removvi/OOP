# Лабораторна робота №3

Графічний редактор на C++ Win32 API з меню, Toolbar та tooltip-підказками.

Для Лабораторної №3 використовується Ж = 17 + 1 = 18.

- Динамічний масив: `Shape** shapes = new Shape*[118]`.
- Гумовий слід: суцільний синій.
- Прямокутник: введення двома кутами, чорний контур без заповнення.
- Еліпс: введення від центра до кута, чорний контур і сіре заповнення.
- Поточний інструмент: позначка в меню «Об’єкти».

Файли:

- `Lab3.cpp` - клас `EditorApp`, головне вікно, меню, Toolbar, обробники повідомлень.
- `Shape.h` - абстрактний клас `Shape` і похідні класи фігур.
- `Shape.cpp` - реалізація малювання та гумового сліду.

Збірка в PowerShell:

```powershell
C:\msys64\ucrt64\bin\g++.exe -std=c++17 -Wall -Wextra -municode -mwindows -static -static-libgcc -static-libstdc++ Lab3.cpp Shape.cpp -lcomctl32 -o Lab3.exe
```

Запуск:

```powershell
.\Lab3.exe
```
